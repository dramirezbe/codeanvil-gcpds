# Codex project configuration compatibility

Status: implemented on `fix/codex-project-compatibility`.

Request: consult current Codex configuration documentation and make projects
generated by `codeanvil create` usable by Codex, including MCP, skills and agents.

## Delivered behavior

- Selected MCP servers use `.codex/config.toml` with native `mcp_servers` tables.
- Enable merges managed entries while preserving unrelated configuration and
  comments; disable removes the selected entry and cleans legacy JSON references.
- Invalid TOML is reported without overwriting it. Disabling validates Codex
  configuration before removing the server's skills.
- Existing native `.agents/skills/` and standalone `.codex/agents/*.toml`
  conventions remain in place. No extra role registration or model pin is needed.
- README documents personal/project/folder configuration, skill and agent
  authoring, project trust, migration and inherited subagent permissions.

[configuration](https://developers.openai.com/codex/config-basic/),
[MCP](https://developers.openai.com/codex/mcp/),
[skills](https://developers.openai.com/codex/skills/),
[instructions](https://developers.openai.com/codex/guides/agents-md/) and
[subagents](https://developers.openai.com/codex/subagents/) documentation.
